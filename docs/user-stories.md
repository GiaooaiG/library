### 6.1 管理员密码重置功能
**作为** 系统管理员
**我想要** 能够重置用户的密码
**以便** 在用户忘记密码或账户被锁定时快速恢复访问

**验收标准 (AC):**
- ✅ 管理员可以在用户管理界面选择"重置密码"操作
- ✅ 系统生成一个临时密码并通过安全方式通知用户
- ✅ 用户首次登录时必须更改临时密码
- ✅ 操作记录在审计日志中
- ✅ 只有管理员角色可以执行此操作

**优先级:** 高
**技术实现:** 后端添加 [`POST /api/v1/admin/users/:id/reset-password`](library-backend/src/services/user/mod.rs) 端点，前端在用户管理界面添加操作按钮

**优先级:** 高
**技术实现:** 后端添加 [`POST /api/v1/books/:id/adjust-inventory`](library-backend/src/services/book/mod.rs) 端点，前端在图书管理界面添加库存调整功能

| 用户登录 | POST | /api/v1/auth/login | 所有用户 |
| 借书 | POST | /api/v1/borrow | 已登录用户 |
| 还书 | POST | /api/v1/return | 已登录用户（本人） |
| 借阅历史 | GET | /api/v1/borrow/history | 已登录用户（本人） |
| 续借图书 | POST | /api/v1/renew/:id | 已登录用户（本人） |
| 库存统计 | GET | /api/v1/statistics/inventory | 所有用户 |
| 借阅排行榜 | GET | /api/v1/statistics/popular-books | 所有用户 |
| 管理员-查看所有用户 | GET | /api/v1/admin/users | 管理员 |
| 管理员-查看所有借阅记录 | GET | /api/v1/admin/borrow-records | 管理员 |
| 管理员-查看用户借阅记录 | GET | /api/v1/admin/users/:id/borrow-records | 管理员 |
| 管理员-重置用户密码 | POST | /api/v1/admin/users/:id/reset-password | 管理员 |
| 管理员-调整图书库存 | POST | /api/v1/books/:id/adjust-inventory | 管理员 |
| 导出用户数据 | GET | /api/v1/export/users | 管理员 |
| 导出图书数据 | GET | /api/v1/export/books | 管理员 |
| 导出借阅记录 | GET | /api/v1/export/borrow-records | 管理员 |

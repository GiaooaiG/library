# 图书馆管理系统产品需求文档 (PRD)

## 1. 目标和背景

### 1.1 目标
- 开发现代化图书馆管理系统，提升图书管理效率
- 实现读者自助借阅服务，减少人工操作
- 提供实时库存统计和数据分析能力

### 1.2 背景
现有图书馆管理系统存在以下痛点：
- 基于陈旧技术栈，维护困难
- 缺乏实时库存管理能力
- 读者服务功能不足
- 多终端访问支持有限

## 2. 需求

### 2.1 功能性需求
#### 图书管理 (FR1-FR4)
1. **FR1: 图书入库**
   - 支持ISBN扫描或手动录入图书信息
   - 自动分类（文学/科技/艺术等）
2. **FR2: 图书检索**
   - 多条件搜索（书名/作者/分类/ISBN）
   - 实时显示库存状态
3. **FR3: 图书下架**
   - 标记损坏/遗失图书
   - 保留历史记录

#### 借阅管理 (FR4-FR7)
4. **FR4: 借书流程**
   - 读者账号验证
   - 借阅数量限制（普通用户5本，VIP用户10本）
5. **FR5: 还书/续借**
   - 扫码快速还书
   - 每本书可续借1次（7天）
6. **FR6: 逾期管理**
   - 自动计算逾期天数
   - 系统锁定超期未还账户

#### 用户系统 (FR8-FR10)
7. **FR8: 读者注册**
   - 手机号/邮箱验证
   - 个人信息管理
8. **FR9: 权限分级**
   | 角色 | 权限 |
   |---|---|
   | 读者 | 借书/查询/续借 |
   | 管理员 | 图书管理/用户管理/报表查看 |
9. **FR10: 密码重置**
   - 管理员重置密码（无邮箱验证）

### 2.2 非功能性需求
1. **NFR1: 性能**
   - 关键操作响应时间 <1s（图书检索/借还书）
   - 支持100+并发用户
2. **NFR2: 安全性**
   - 本地密码验证（无需邮箱）
   - 基础权限控制
3. **NFR3: 数据持久性**
   - 本地MySQL数据库
   - 事务性操作保证（借/还书）
4. **NFR4: 运行环境**
   - 本地开发环境
   - 支持Windows/Mac/Linux

## 3. 用户界面设计目标
1. **响应式设计**
   - 适配桌面/平板/手机端
   - 管理员使用桌面优化界面
   - 读者优先移动端体验

2. **无障碍标准**
   - WCAG AA合规
   - 键盘导航支持
   - 高对比度模式

3. **品牌一致性**
   - 蓝色系主色调（#2563EB）
   - 简洁卡片式布局
   - 图书馆行业图标库

## 4. 技术假设（学校作业版）
### 后端架构
- **框架**: Actix-web 4.0
- **数据库**: MySQL 8.0（本地安装）
- **身份验证**: 本地密码验证（无邮箱）

### 关键约束（无服务器依赖）
1. 本地MySQL数据库（无需云部署）
2. 所有数据库操作必须事务化
3. 前后端可本地联调
4. 支持一键启动脚本
5. **移除功能**：
   - 邮箱认证
   - 在线部署
   - 实时通知
   - 云存储

## 技术架构总结

### 系统架构
```
前端表现层 (React + TypeScript)
    ↓
API网关 (JWT认证 + 权限控制)
    ↓
业务逻辑层 (Rust + Actix-web)
    ↓
数据访问层 (Diesel ORM)
    ↓
数据存储层 (MySQL数据库)
```

### 核心数据表
1. **用户表（users）**：存储用户基本信息和权限
2. **图书表（books）**：存储图书详细信息和库存状态
3. **借阅记录表（borrow_records）**：存储借阅历史记录

### 关键技术特性
- **现代化技术栈**：Rust + React + MySQL
- **安全认证**：JWT令牌认证机制
- **权限控制**：基于RBAC模型的细粒度权限
- **性能优化**：合理的索引设计和查询优化
- **数据完整性**：完善的外键约束和业务规则

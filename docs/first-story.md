# 第一个用户故事：创建图书管理基础

## 故事1.1：图书入库功能
**作为** 图书管理员  
**我想要** 添加新图书到系统  
**以便** 读者可以借阅这些图书  

### 验收标准
1. ✅ 可以输入图书基本信息（ISBN、书名、作者）
2. ✅ 系统自动验证ISBN格式
3. ✅ 保存成功后显示确认信息
4. ✅ 处理重复ISBN的异常情况

### 技术实现
- **后端**：POST /api/v1/books
- **前端**：图书添加表单
- **数据库**：books表插入操作

### 开发步骤
1. 创建数据库迁移
2. 实现后端API
3. 开发前端表单
4. 集成测试

## 立即开始
1. **运行数据库迁移**：
   ```bash
   cd library-backend
   diesel migration run
   ```

2. **启动开发**：
   ```bash
   # 后端
   cargo run
   
   # 前端（新终端）
   npm run dev

# 第四章 系统实现

## 4.1 系统开发工具简介与环境配置

### 4.1.1 开发工具简介

本图书馆管理系统采用现代化的技术栈，结合高性能后端和现代化前端框架，确保系统的稳定性、安全性和用户体验。

#### 后端开发工具
- **Rust 1.75+**: 系统后端采用Rust语言开发，Rust是一门系统级编程语言，具有内存安全、零成本抽象和高性能的特点
- **Actix-web 4.0**: 基于Actor模型的Web框架，提供异步处理能力和优秀的性能表现
- **Diesel ORM 2.0**: Rust的ORM框架，提供类型安全的SQL查询构建和数据库迁移功能
- **PostgreSQL/OpenGauss**: 采用企业级关系型数据库，支持复杂查询和事务处理

#### 前端开发工具
- **React 18**: 现代化的JavaScript库，采用组件化开发模式
- **TypeScript**: 为JavaScript添加静态类型检查，提高代码质量和开发效率
- **Vite**: 快速的构建工具，提供热重载和优化的开发体验
- **Ant Design**: 企业级UI组件库，提供丰富的界面组件

#### 开发环境工具
- **Visual Studio Code**: 主流代码编辑器，支持Rust和TypeScript的智能提示
- **Docker**: 容器化部署工具，用于运行OpenGauss数据库
- **Git**: 版本控制系统，用于代码管理和协作开发

## 4.3 数据库的连接

### 4.3.1 数据库连接架构

系统采用分层架构实现数据库连接管理，确保连接的高效性和安全性：

```
应用层 (Actix-web handlers)
    ↓
服务层 (Business logic)
    ↓
数据访问层 (Diesel ORM)
    ↓
连接池层 (R2D2 connection pool)
    ↓
数据库层 (OpenGauss)
```

### 4.3.2 数据库连接配置

数据库连接配置在 [`library-backend/.env`](library-backend/.env:1) 文件中定义：

```env
DATABASE_URL=postgres://gaussdb:opengaussDB%40123456@localhost:15432/library_db
```

连接字符串格式说明：
- `postgres://`: PostgreSQL/OpenGauss协议标识
- `gaussdb`: 数据库用户名
- `opengaussDB%40123456`: 密码（@符号已URL编码为%40）
- `localhost:15432`: 数据库服务器地址和端口
- `library_db`: 数据库名称

### 4.3.3 连接池实现

系统在 [`db.rs`](library-backend/src/db.rs:1) 文件中实现了连接池管理：

```rust
use diesel::prelude::*;
use diesel::r2d2::{ConnectionManager, Pool, PooledConnection};
use std::env;

pub type DbPool = Pool<ConnectionManager<PgConnection>>;
pub type DbConn = PooledConnection<ConnectionManager<PgConnection>>;

pub fn establish_connection() -> DbPool {
    let database_url = env::var("DATABASE_URL")
        .expect("DATABASE_URL must be set in .env file");
    
    let manager = ConnectionManager::<PgConnection>::new(database_url);
    
    Pool::builder()
        .max_size(16)  // 最大连接数
        .min_idle(Some(4))  // 最小空闲连接数
        .connection_timeout(std::time::Duration::from_secs(30))
        .build(manager)
        .expect("Failed to create database pool")
}
```

### 4.4.2 JWT认证机制

系统在 [`middleware.rs`](library-backend/src/middleware.rs:1) 文件中实现了JWT认证中间件：

```rust
use jsonwebtoken::{decode, Validation, DecodingKey};
use serde::{Deserialize, Serialize};

#[derive(Debug, Serialize, Deserialize)]
pub struct Claims {
    pub sub: String,        // 用户ID
    pub username: String,   // 用户名
    pub role: String,       // 用户角色
    pub exp: i64,          // 过期时间
}

pub fn validate_token(token: &str) -> Result<Claims, jsonwebtoken::errors::Error> {
    let jwt_secret = std::env::var("JWT_SECRET")
        .expect("JWT_SECRET must be set");
    
    decode::<Claims>(
        token,
        &DecodingKey::from_secret(jwt_secret.as_ref()),
        &Validation::default(),
    ).map(|data| data.claims)
}
```

### 4.4.3 权限检查中间件

实现了基于角色的权限检查中间件：

```rust
use actix_web::{dev::ServiceRequest, Error, HttpMessage};
use actix_web_httpauth::extractors::bearer::BearerAuth;

pub async fn validator(
    req: ServiceRequest,
    credentials: BearerAuth,
) -> Result<ServiceRequest, (Error, ServiceRequest)> {
    let token = credentials.token();
    
    match validate_token(token) {
        Ok(claims) => {
            // 将用户信息添加到请求扩展中
            req.extensions_mut().insert(claims);
            Ok(req)
        }
        Err(_) => {
            Err((actix_web::error::ErrorUnauthorized("Invalid token"), req))
        }
    }
}
```

### 4.4.5 权限控制实现

```rust
// 管理员权限检查
pub fn require_admin(claims: &Claims) -> Result<(), ApiError> {
    if claims.role != "admin" {
        return Err(ApiError::Forbidden("Admin access required".to_string()));
    }
    Ok(())
}

// 用户只能访问自己的数据
pub fn require_owner_or_admin(
    claims: &Claims,
    user_id: i32,
) -> Result<(), ApiError> {
    if claims.role != "admin" && claims.sub != user_id.to_string() {
        return Err(ApiError::Forbidden("Access denied".to_string()));
    }
    Ok(())
}
```

### 4.4.6 前端权限控制

前端在 [`useAuth.ts`](library-frontend/src/hooks/useAuth.ts:1) 中实现权限控制：

```typescript
export interface AuthUser {
  id: number;
  username: string;
  role: 'admin' | 'user';
  token: string;
}

export function useAuth() {
  const [user, setUser] = useState<AuthUser | null>(null);
  
  const isAdmin = () => user?.role === 'admin';
  const isAuthenticated = () => !!user;
  
  const requireAuth = (requiredRole?: 'admin' | 'user') => {
    if (!isAuthenticated()) {
      throw new Error('Authentication required');
    }
    if (requiredRole && user?.role !== requiredRole) {
      throw new Error(`Role ${requiredRole} required`);
    }
  };
  
  return { user, isAdmin, isAuthenticated, requireAuth };
}
```

### 4.5.2 用户注册功能实现

用户注册功能在 [`user/create.rs`](library-backend/src/services/user/create.rs:1) 中实现：

```rust
use argon2::{self, Config, ThreadMode, Variant, Version};
use rand::Rng;

#[derive(Debug, Serialize, Deserialize)]
pub struct RegisterRequest {
    pub username: String,
    pub password: String,
    pub phone: Option<String>,
}

pub async fn register_user(
    pool: web::Data<DbPool>,
    user_data: web::Json<RegisterRequest>,
) -> Result<HttpResponse, ApiError> {
    let mut conn = pool.get()?;
    
    // 检查用户名是否已存在
    let existing_user = users::table
        .filter(users::username.eq(&user_data.username))
        .first::<User>(&mut conn)
        .optional()?;
    
    if existing_user.is_some() {
        return Err(ApiError::BadRequest("Username already exists".to_string()));
    }
    
    // 密码哈希处理
    let password_hash = hash_password(&user_data.password)?;
    
    let new_user = NewUser {
        username: user_data.username.clone(),
        password_hash,
        role: UserRole::User,
        phone: user_data.phone.clone(),
        created_at: chrono::Local::now().naive_local(),
        updated_at: chrono::Local::now().naive_local(),
    };
    
    let user = diesel::insert_into(users::table)
        .values(&new_user)
        .get_result::<User>(&mut conn)?;
    
    Ok(HttpResponse::Created().json(user))
}

fn hash_password(password: &str) -> Result<String, ApiError> {
    let salt = rand::thread_rng().gen::<[u8; 32]>();
    let config = Config {
        variant: Variant::Argon2id,
        version: Version::Version13,
        mem_cost: 65536,
        time_cost: 3,
        lanes: 4,
        thread_mode: ThreadMode::Parallel,
        secret: &[],
        ad: &[],
        hash_length: 32
    };
    
    let hash = argon2::hash_encoded(password.as_bytes(), &salt, &config)
        .map_err(|_| ApiError::InternalServerError)?;
    
    Ok(hash)
}
```

### 4.5.3 借阅记录创建功能

借阅记录创建在 [`borrow/create.rs`](library-backend/src/services/borrow/create.rs:1) 中实现：

```rust
#[derive(Debug, Serialize, Deserialize)]
pub struct CreateBorrowRequest {
    pub book_id: i32,
    pub due_days: Option<i32>, // 借阅天数，默认30天
}

pub async fn create_borrow_record(
    pool: web::Data<DbPool>,
    borrow_data: web::Json<CreateBorrowRequest>,
    claims: Claims,
) -> Result<HttpResponse, ApiError> {
    let mut conn = pool.get()?;
    let user_id = claims.sub.parse::<i32>()?;
    
    // 检查图书是否存在且可借
    let book = books::table
        .find(borrow_data.book_id)
        .first::<Book>(&mut conn)?;
    
    if book.available_copies <= 0 {
        return Err(ApiError::BadRequest("Book not available".to_string()));
    }
    
    // 检查用户是否已借阅此书且未归还
    let existing_borrow = borrow_records::table
        .filter(borrow_records::user_id.eq(user_id))
        .filter(borrow_records::book_id.eq(borrow_data.book_id))
        .filter(borrow_records::status.eq("borrowed"))
        .first::<BorrowRecord>(&mut conn)
        .optional()?;
    
    if existing_borrow.is_some() {
        return Err(ApiError::BadRequest("Already borrowed this book".to_string()));
    }
    
    let due_date = chrono::Local::now()
        .naive_local()
        + chrono::Duration::days(borrow_data.due_days.unwrap_or(30) as i64);
    
    let new_borrow = NewBorrowRecord {
        user_id,
        book_id: borrow_data.book_id,
        borrow_date: chrono::Local::now().naive_local(),
        due_date,
        return_date: None,
        status: BorrowStatus::Borrowed,
        renewal_count: 0,
    };
    
    // 开始事务
    conn.transaction(|conn| {
        // 创建借阅记录
        let borrow_record = diesel::insert_into(borrow_records::table)
            .values(&new_borrow)
            .get_result::<BorrowRecord>(conn)?;
        
        // 更新图书可用数量
        diesel::update(books::table.find(borrow_data.book_id))
            .set(books::available_copies.eq(books::available_copies - 1))
            .execute(conn)?;
        
        Ok(borrow_record)
    }).map_err(|e: diesel::result::Error| ApiError::from(e))
    .map(|record| HttpResponse::Created().json(record))
}
```

### 4.6.1 图书删除功能实现

```rust
pub async fn delete_book(
    pool: web::Data<DbPool>,
    book_id: web::Path<i32>,
    claims: Claims,
) -> Result<HttpResponse, ApiError> {
    // 权限检查 - 只有管理员可以删除图书
    require_admin(&claims)?;
    
    let mut conn = pool.get()?;
    let book_id = book_id.into_inner();
    
    // 检查图书是否存在
    let book = books::table
        .find(book_id)
        .first::<Book>(&mut conn)
        .optional()?;
    
    if book.is_none() {
        return Err(ApiError::NotFound("Book not found".to_string()));
    }
    
    // 检查是否有未归还的借阅记录
    let active_borrows = borrow_records::table
        .filter(borrow_records::book_id.eq(book_id))
        .filter(borrow_records::status.eq("borrowed"))
        .count()
        .get_result::<i64>(&mut conn)?;
    
    if active_borrows > 0 {
        return Err(ApiError::BadRequest(
            "Cannot delete book with active borrow records".to_string()
        ));
    }
    
    // 删除图书（级联删除相关借阅记录）
    diesel::delete(books::table.find(book_id))
        .execute(&mut conn)?;
    
    Ok(HttpResponse::Ok().json(json!({
        "message": "Book deleted successfully",
        "book_id": book_id
    })))
}
```

### 4.6.2 用户删除功能实现

用户删除功能在 [`user/delete.rs`](library-backend/src/services/user/delete.rs:1) 中实现：

```rust
pub async fn delete_user(
    pool: web::Data<DbPool>,
    user_id: web::Path<i32>,
    claims: Claims,
) -> Result<HttpResponse, ApiError> {
    let mut conn = pool.get()?;
    let target_user_id = user_id.into_inner();
    let current_user_id = claims.sub.parse::<i32>()?;
    
    // 权限检查 - 管理员可以删除任何用户，用户可以删除自己
    if claims.role != "admin" && current_user_id != target_user_id {
        return Err(ApiError::Forbidden("Insufficient permissions".to_string()));
    }
    
    // 不能删除管理员账号
    let target_user = users::table
        .find(target_user_id)
        .first::<User>(&mut conn)?;
    
    if target_user.role == UserRole::Admin {
        return Err(ApiError::BadRequest("Cannot delete admin user".to_string()));
    }
    
    // 检查用户是否有未归还的图书
    let active_borrows = borrow_records::table
        .filter(borrow_records::user_id.eq(target_user_id))
        .filter(borrow_records::status.eq("borrowed"))
        .count()
        .get_result::<i64>(&mut conn)?;
    
    if active_borrows > 0 {
        return Err(ApiError::BadRequest(
            "Cannot delete user with active borrow records".to_string()
        ));
    }
    
    // 删除用户（级联删除相关借阅记录）
    diesel::delete(users::table.find(target_user_id))
        .execute(&mut conn)?;
    
    Ok(HttpResponse::Ok().json(json!({
        "message": "User deleted successfully",
        "user_id": target_user_id
    })))
}
```

### 4.6.3 借阅记录删除功能

借阅记录删除实现软删除机制，主要更新记录状态：

```rust
pub async fn cancel_borrow_record(
    pool: web::Data<DbPool>,
    record_id: web::Path<i32>,
    claims: Claims,
) -> Result<HttpResponse, ApiError> {
    let mut conn = pool.get()?;
    let record_id = record_id.into_inner();
    let user_id = claims.sub.parse::<i32>()?;
    
    // 获取借阅记录
    let borrow_record = borrow_records::table
        .find(record_id)
        .first::<BorrowRecord>(&mut conn)?;
    
    // 权限检查
    require_owner_or_admin(&claims, borrow_record.user_id)?;
    
    // 只能取消未归还的记录
    if borrow_record.status != BorrowStatus::Borrowed {
        return Err(ApiError::BadRequest(
            "Can only cancel active borrow records".to_string()
        ));
    }
    
    // 开始事务
    conn.transaction(|conn| {
        // 更新借阅记录状态为已归还
        diesel::update(borrow_records::table.find(record_id))
            .set((
                borrow_records::status.eq(BorrowStatus::Returned),
                borrow_records::return_date.eq(Some(chrono::Local::now().naive_local())),
            ))
            .execute(conn)?;
        
        // 增加图书可用数量
        diesel::update(books::table.find(borrow_record.book_id))
            .set(books::available_copies.eq(books::available_copies + 1))
            .execute(conn)?;
        
        Ok(())
    }).map_err(|e: diesel::result::Error| ApiError::from(e))?;
    
    Ok(HttpResponse::Ok().json(json!({
        "message": "Borrow record cancelled successfully",
        "record_id": record_id
    })))
}
```

```rust
    pool: web::Data<DbPool>,
    record_id: web::Path<i32>,
    renew_data: web::Json<RenewBorrowRequest>,
    claims: Claims,

    // 检查是否可以续借

        ));
    }
    
    // 检查续借次数限制（最多续借3次）

        return Err(ApiError::BadRequest(
            "Maximum renewal count reached".to_string()
        ));
    }

    let additional_days = renew_data.additional_days.unwrap_or(30);

    // 更新借阅记录
    diesel::update(borrow_records::table.find(record_id))
        .set((
            borrow_records::due_date.eq(new_due_date),
            borrow_records::renewal_count.eq(borrow_record.renewal_count + 1),
        ))
        .execute(&mut conn)?;
    
    // 获取更新后的记录
    let updated_record = borrow_records::table
        .find(record_id)
        .first::<BorrowRecord>(&mut conn)?;
    
    Ok(HttpResponse::Ok().json(updated_record))
```

```rust
            books::title,
            books::author,

        ))
        .order(diesel::dsl::count(borrow_records::id).desc())
        .limit(10)
        .load::<PopularBook>(&mut conn)?;
    
    // 获取借阅趋势（最近30天）
```
